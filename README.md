## How I take notes

Every notebook follows the same shape:

1. **Goal:** what I'm trying to learn this week
2. **Concept in my own words:** a short explanation, no copying
3. **Worked examples:** code with comments
4. **Practice:** exercises, ideally on real data
5. **What confused me:** the honest part
6. **Takeaway:** one or two sentences

If I can't explain a concept simply in step 2, I haven't understood it yet.

## Data policy

All data in this repo is public, synthetic, or properly anonymized. No employer, supplier, or customer data appears here, ever.
